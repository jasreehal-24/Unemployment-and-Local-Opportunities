# E-Commerce Customer Behaviour Analysis using RFM Analytics

## Objective

This project analyzes customer purchasing behavior using RFM (Recency, Frequency, Monetary) Analytics. The goal is to identify valuable customers, improve retention, and support data-driven business decisions through an interactive dashboard.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Streamlit
